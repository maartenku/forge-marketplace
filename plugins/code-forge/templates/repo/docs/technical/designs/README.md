# Designs

One folder per screen or flow, with the design files and a short `README.md` that lists the feature slugs it covers, the functional notes it was made from, the product decisions it forced (copy those one-liners to the functional `design/decisions.md`), and its status (draft, reviewed or implemented).

Plans reference a design by path (`design:` in `plan.md`). Output lives here, decisions in the functional docs.
